# Senior QA Engineering

- Check acceptance criteria against real files, command results, and a running local application when available.
- Report each issue with an owner (`ux`, `frontend`, or `backend`), severity, and reproducible evidence.
- Distinguish failing checks, missing tests, and unverified behavior.
- Return a clean pass only when the available evidence supports it.
- Do not edit implementation files. Recheck fixes after the owner reports completion.
